# 🌱 디지털새싹 현수막 자동 생성기 (Sprout Banner Generator)

초·중·고등학생 대상 디지털새싹 행사를 위한 고해상도 현수막 자동 제작 및 다운로드 도구입니다.

## 주요 기능
- **실시간 미리보기 및 다운로드**: 슬라이드 크기 및 인쇄에 최적화된 고해상도(3000px 가로폭) 현수막 JPG 즉시 생성 및 다운로드.
- **다양한 디자인 테마**: 새싹 연두, 디지털 블루, 네온 퍼플, 선셋 오렌지, 사이버 에메랄드 테마 지원.
- **교육 대상 최적화**: 초등, 중등, 고등, 공통 영역별 맞춤 캐릭터 마스코트 렌더링.
- **비율(규격) 설정**: 5:1 현수막 표준 비율, 3:1 파워포인트 삽입 비율, 32:9 슬라이드 반 크기 비율 제공.
- **커스텀 파일 업로드**: 배경 이미지 단일/폴더(랜덤) 교체 및 개별 캐릭터/로고 이미지 파일 적용 가능.
- **고급 동적 백그라운드**: 자라나는 디지털새싹을 직관적으로 연상시키는 베지에 곡선 웨이브, 보케 빛망울, 반짝이 효과 및 기술 네트워크 격자 드로잉 탑재.

## 기술 스택
- HTML5 / CSS3 (Glassmorphism & Flexbox Grid)
- JavaScript (HTML5 Canvas API - Dynamic Vector Graphics drawing)
- Google Fonts (Do Hyeon, Noto Sans KR)
